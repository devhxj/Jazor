# 1,000 行带 key 的列表生产基线

两份页面共用数据、事件回调、CSS、入口和 `pnpm-lock.yaml`。Jolt 使用 `@foreach` 和 `@key`，SFC 使用 Vue 的生产 SFC 编译器编译 `v-for` 和 `:key`。两份页面都通过 Vite 8.2.0 生产构建，使用 Vue 3.5.42。

## 复现

```powershell
dotnet build src/Jolt.Cli/Jolt.Cli.csproj -c Release
dotnet run --file samples/Jolt.Counter/benchmark-keyed-rows.cs -- "$PWD/src/Jolt.Cli/bin/Release/net11.0/Jolt.Cli.exe" "<Chrome 或 Chromium 的绝对路径>" "$PWD/.tmp/keyed-rows.json"
```

每批使用一个全新的 Chrome 配置和同一个浏览器标签页。每轮分别打开各版本页面。两份页面交替先测版本，传入第四个参数指定旧版 Jolt apphost 时，同一批按六种排列轮换测量候选版、旧版和 SFC。每份页面预热 6 次，再采样 24 次。JSON 记录全部样本、环境、采样顺序，以及夹具、锁文件、生产 JavaScript 和 CLI 的 SHA-256。p50 和 p95 按最近秩取样。

挂载从 Vue 应用创建起测到 `mount()` 返回。其余操作从程序触发按钮点击起测到 `nextTick()`，包括响应式状态更新、渲染和 DOM 提交。页面模块预先加载，计时区间止于 DOM 提交，绘制和时钟外的断言另计。JavaScript 字节数覆盖页面的全部生产 JavaScript，gzip 逐文件采用 .NET `CompressionLevel.SmallestSize`。源映射和共享 CSS 独立于这些体积指标。

每次采样都断言完整行顺序、文本、已有行的 DOM 对象身份和事件次数。修改第 500 号键对应行的显示值和首部插入分别观察到一行发生 DOM 变化。倒序让 1,000 行发生 DOM 移动，并复用全部 1,001 行。修改和插入时在原有行的输入框核对焦点与草稿。倒序前把焦点移到插入的行，核对 Vue 保留在原处的节点仍承载焦点和草稿。该场景的焦点断言覆盖倒序中留在原处的节点。

## Vue 渲染块实验

用 Chrome 158.0.8127.36 的 DevTools CPU Profiler 分别采样 14 轮生产页面。Jolt 的热点包括 VNode 创建、子节点归一化、keyed diff 和原生元素属性更新。Jolt 每行创建四个缩进空白文本节点，另外为 `span` 和按钮生成独立的文本 VNode。SFC 省略这四段缩进，将 `span` 和按钮的内容作为字符串传给 Vue，并用 patch flag 标记动态节点。Jolt 只在读取列表、解释第 500 行的标签和触发事件时才读取对应 prop，逐行读取 prop 别名并非该夹具的热点。

在临时产物中将固定形状的原生行改为 Vue 渲染块，沿用原有空白和文本节点、key、事件回调及属性逻辑。第二批先按源码顺序求值属性和文本表达式，再开启渲染块，避免表达式创建的其他 VNode 被 Vue 纳入当前块。每批将实验产物、同一 Jolt 基线和 SFC 放在同一浏览器轮换测量，每种产物预热 6 次并采样 24 次。全部行顺序、文本、DOM 身份、焦点、草稿与事件断言通过。

## 原生元素单文本子节点实验

另从编译器发射端生成 Vue 字符串子节点，限定为 `button`、`span`、`p` 和 `div` 中的单个非空文本字面量或单个静态类型为 `string` 的表达式。保留 `toDisplayString`、原有属性求值顺序以及片段的数组语义。Release CLI 构建和 132 个 Jolt 编译器测试通过，两批浏览器测量中的列表断言均通过。

两批均使用无头 Chrome 158.0.8127.36，在同一标签页内轮换旧版、候选版和 SFC。

Vue 对字符串子节点使用 `textContent`，更新时会替换已有文本节点，空字符串也不再生成空 Text 节点。原有数组路径保留文本节点并更新其内容。由于这一语义差异和倒序回归，实验代码已撤回，未进入 SSR 验证。
