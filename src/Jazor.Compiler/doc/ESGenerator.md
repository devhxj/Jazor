# ESGenerator 分析文档

## 1. 文件概述

**文件路径**: `ESGenerator.cs`

**职责**: 增量源生成器，为标记 `[ECMAScriptModule]` 的类生成 JavaScript 模块。

## 2. 核心设计思路

### 2.1 源生成器架构

```
编译过程
    │
    ▼
检测 [ECMAScriptModule] 特性
    │
    ▼
提取 ClassDeclarationSyntax
    │
    ▼
调用 AstConverter 转换
    │
    ▼
生成 .mjs 文件
```

### 2.2 增量生成管道

```csharp
var classDecls = context.SyntaxProvider.ForAttributeWithMetadataName(
    "ECMAScript.ECMAScriptModuleAttribute",
    predicate: (node, _) => node is ClassDeclarationSyntax,
    transform: (context, _) => (context.TargetNode, context.SemanticModel)
);

context.RegisterImplementationSourceOutput(classDecls, (outputContext, transform) =>
{
    // 转换并生成代码
});
```

## 3. 已知缺陷

### 3.1 严重缺陷 🔴

| 缺陷 | 影响 | 严重程度 |
|------|------|---------|
| **未实际转换 AST 到 JavaScript** | 生成的是占位代码 | 🔴 严重 |
| **生成的是 .mjs 而非嵌入资源** | 与设计不符 | 🟡 中等 |

### 3.2 当前生成代码

```javascript
// Generated from {className}
// TODO: Implement AST to JavaScript conversion
export class {className} {
  constructor() {
    // TODO
  }
}
```

### 3.3 应该生成的内容

应该调用 `AstConverter.Convert()` 并将 AST 转换为 JavaScript 代码字符串：

```csharp
// 应该的实现
var jsAst = astConverter.Convert();
var jsCode = jsAst?.ToECMAScript() ?? "// Empty module";
outputContext.AddSource($"{className}.mjs", jsCode);
```

## 5. 设计改进建议

### 5.1 输出策略

当前设计输出 `.mjs` 文件，建议：

**方案 A**: 输出嵌入资源
```csharp
outputContext.AddSource($"{className}.ECMAScript.g.cs",
    $"// <auto-generated/>\n// JavaScript: {jsCode}");
```

**方案 B**: 输出到指定目录
```csharp
// 需要额外的 MSBuild 集成
File.WriteAllText(Path.Combine(outputPath, $"{className}.mjs"), jsCode);
```

### 5.2 错误处理

建议添加详细的错误报告：

```csharp
catch (OperationTransformationException ex)
{
    var diagnostic = Diagnostic.Create(
        new DiagnosticDescriptor(...),
        location,
        ex.Message);
    outputContext.ReportDiagnostic(diagnostic);
}
```
