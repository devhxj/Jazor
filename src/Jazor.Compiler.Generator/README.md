# Jazor.Compiler.Generator

## 概述

`Jazor.Compiler.Generator` 是 Jazor 编译器项目的源代码生成工具，负责扫描 ECMAScript.CLR 和相关程序集，自动生成编译器白名单代码。

## 功能说明

本程序通过反射扫描带有 `JazorAttribute` 注解的类型和成员，生成三个核心文件：

### 1. 白名单数据生成

生成文件：`Jazor.Compiler/WhiteList.cs.Generate.cs`

```csharp
internal static partial class WhiteList
{
    static partial void Generate(ref Dictionary<string, WhiteListValue> types,
                                 ref Dictionary<string, WhiteListValue> members)
    {
        // 自动生成类型和成员的白名单初始化代码
    }
}
```

### 2. 特殊处理方法接口

生成文件：`Jazor.Compiler/WhiteList.cs.Compile.cs`

```csharp
partial interface IWhiteList
{
    Expression? Compile{HashName}(Expression? handler, Expression?[] args);
    // 为每个需要特殊编译的方法生成接口定义
}
```

### 3. 特殊处理方法字典

生成文件：`Jazor.Compiler/core/SemanticWalker.cs.Generate.cs`

```csharp
public partial class SemanticWalker
{
    partial void Generate(ref Dictionary<string, Func<Expression?, Expression?[], Expression?>> funcs)
    {
        // 生成方法名称到编译处理函数的映射
    }
}
```

## JazorAttribute 注解说明

`JazorAttribute` 用于标记需要 Jazor 编译器特殊处理的类型和成员：

| Op 枚举 | 说明 | 用法 |
|---------|------|------|
| `Discard` | 不支持，丢弃 | 过滤掉不需要处理的成员 |
| `Allowed` | 支持，无其他操作 | 标记为允许使用的类型/成员 |
| `Alias` | 支持，替换名称 | 将 C# 名称替换为指定的 JavaScript 名称 |
| `Import` | 作为模块导入 | 标记为从外部模块导入 |
| `Inline` | 内联代码调用 | 直接嵌入 JavaScript 代码片段 |
| `Compile` | 编译器特殊处理 | 生成专门的编译处理方法 |

### 使用示例

```csharp
// 标记为允许使用
[Jazor]
public static class ObjectModule { }

// 替换名称
[Jazor(Op.Alias, "console","console")]
public static class ConsoleModule { }

// 内联代码
[Jazor("@#{0}.length")]
public static extern Number StringLength(string instance);

// 特殊编译处理
[Jazor]
public static bool BooleanParse(string value) { /* ... */ }
```

## 构建与运行

```bash
# 构建项目
dotnet build

# 运行生成器
dotnet run
```

运行后会在 `Jazor.Compiler` 项目中生成以下文件：
- `WhiteList.cs.Generate.cs`
- `WhiteList.cs.Compile.cs`
- `core/SemanticWalker.cs.Generate.cs`

## 输出示例

生成器会输出类似以下内容的代码：

```csharp
// WhiteList.cs.Generate.cs
types["System.Object"] = new(Op.Allowed);
types["console"] = new(Op.Alias, "console");
members["static string.Concat(string, string)"] = new(Op.Inline, "@#{0}.concat(@#{1})");

// WhiteList.cs.Compile.cs
Expression? Compilea3f8c2d1(Expression? handler, Expression?[] args);

// SemanticWalker.cs.Generate.cs
funcs["static bool.Parse(string)"] = Compilea3f8c2d1;
```

## 注意事项

1. **手动实现编译方法**：生成器只为 `Op.Compile` 类型的方法生成接口定义和字典映射，实际的编译处理逻辑需要手动实现
2. **代码覆盖**：生成器生成的文件标记为 `<auto-generated/>`，不应手动编辑
3. **名称哈希**：编译方法使用 SHA256 哈希值命名，确保唯一性
4. **属性处理**：属性会被展开为 get/set 两个方法分别处理
