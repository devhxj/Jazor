# ECMAScript.Vben.TDesign

TDesign-backed admin-shell adapter components for `ECMAScript.Vben`.

Scope of this package:

- production-first Razor authoring surface for admin layout shells
- TDesign-backed sidebar, header, and page container composition
- stable mapping from `ECMAScript.Vben` semantic contracts to `ECMAScript.TDesign`

This package is the first concrete adapter line for `ECMAScript.Vben`. `ECMAScript.ElementPlus` support remains a later adapter line.
