# 遗弃材料

本目录保存不再指导当前实现的方案、任务记录和阶段性评估，仅用于追溯设计背景。这里的内容不属于当前产品契约，也不应作为实施计划、测试结论或发布说明的直接依据。

## 文件索引

| 目录或文件 | 说明 |
| --- | --- |
| `obsolete/` | 已废弃的架构方案与阶段评估 |
| `tasks/` | 历史任务清单、开发规则和测试规则 |

## 使用规则

- 引用遗弃材料时，应同时说明其历史状态和适用时间。
- 遗弃材料中的 API、路径、测试数量和完成度不得直接代表当前实现。
- 若历史材料重新成为产品需求，应先迁移到 `01-目标` 或 `02-计划`，补充当前源码与测试证据后再执行。
