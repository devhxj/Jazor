- Deno production toolchain import-backed asset 输出首切片：manifest 中由组件引用派生的 `.vue` SFC style 汇总输出 `bundle.css`，static asset 复制到 output root，bundle source-map 保留 SFC 编译产物来源，不扫描 source root。
- Deno production toolchain import-backed `.vue` SFC browser smoke：真实浏览器加载 production `bundle.js` + `bundle.css`，验证 SFC DOM 与 CSS 生效，不扫描 source root。
- Netpack production toolchain 首切片：`NetPack.Core` lane 消费同一 manifest/request/result contract，输出 `bundle.js` / `bundle.js.map`，覆盖纯 `.mjs`、import-derived `.vue` SFC asset 与 manifest static asset 输出，不走 Deno fallback。
- Netpack production toolchain import-backed `.vue` SFC browser smoke：真实浏览器加载 Netpack production `bundle.js`，验证组件引用派生的 SFC DOM 渲染，不扫描 source root。
- Netpack production toolchain Vuetify browser smoke：真实浏览器加载 Netpack production `bundle.js`，验证真实 `vuetify/components/VBtn` package import 与 CSS side-effect 注入。
- Netpack package consumer smoke：外部 Razor SG consumer 通过本地 `Jazor` NuGet package 启用 `JazorBundle=true` + `JazorToolchain=Netpack`，生成 `wwwroot/netpack/bundle.js` / `.map`，并覆盖 manifest 内模块裸导入重写为 Netpack workspace 相对导入，不走 Deno fallback。
