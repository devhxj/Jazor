- Direct VNode emitter P1-D render surface 扩面：`OpenRegion` / `CloseRegion` 直接生成 `Fragment`，`AddMarkupContent` 直接生成 `createStaticVNode`，非泛型 named/default `RenderFragment` slot 与 typed `RenderFragment<T>` scoped slot 直接生成 Vue slots object。
- Direct VNode emitter P1-D element metadata/bind 扩面：`SetKey`、`SetAttributeValue`、静态可解析 `AddMultipleAttributes`、DOM `SetUpdatesAttributeName` bind handler、prevent/stop event modifier、named event metadata 直接生成/消费为 Vue props/listener shape。
- Direct VNode emitter parser robustness：使用 `Stack<DirectRenderFrame>` 维护 element/component/region 嵌套，`Close*` 与 props 类调用按 frame 类型校验；多行 builder call 折叠用于 lambda/ref/scoped-slot 参数，不引入运行时 fallback。

## 当前缺口

- Direct core surface 已覆盖：element/component roots、attributes/events、component props/listeners、default/named/typed scoped slots、markup/static VNode、regions/Fragment、static-readable bulk attrs、`SetKey`、bind metadata、ref capture 与 source-map projection。
- 继续显式 unsupported：dynamic `Type` `OpenComponent(int, Type)`，不静默生成半成品 `.mjs`。
- 继续由 render-context oracle/过渡层覆盖：`AddComponentRenderMode` metadata、`Clear` / `GetFrames` / `Dispose` / `RenderTreeBuilder()` 等管理/诊断 surface，以及 direct parser 无法静态解析的动态 bulk attribute carrier。
- G2 性能 baseline 已完成：runtime protocol、browser heap、generated artifact gzip/build time、old-line baseline availability。
- G2 baseline 已记录到 [performance-report-2026-07-27.md](../../03-完成/razorvue/performance-report-2026-07-27.md)：generated gzip 与 Node throughput 当前为 warn，browser heap 已观测，`v0.1.26` 无同构 G2 protocol。
