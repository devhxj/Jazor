# Archive

- [Testing 历史审计](./testing/README.md)

本目录用于保存历史材料、一次性报告，以及已经被总文档吸收后的原文。说白了，就是这些文档还值得留到起，但已经不再直接指挥当前执行了。

## 进入 archive 的常见场景

- 旧阶段状态快照已经被新快照替代
- 旧执行计划已经被新的 repo-level bridge 或 program roadmap 吸收
- 某份文档主要只剩历史上下文价值，不再直接指导当前推进

## 保留规则

- 进入 archive，不等于没得参考价值
- archive 里的文档，当前文档还是可以拿来当历史上下文引用
- 但 archive 文档不应继续充当 repo-level 主入口
