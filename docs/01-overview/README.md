# 产品概览

先在这里建立一个共同判断：Jazor 解决的是受支持 C# 语义如何有序抵达浏览器的问题，而不是把任意 .NET 运行时搬到前端。进入项目、包和实现细节之前，请先确认它当前承诺哪些产品路径，以及每一层应在何处止步。

| 文档 | 说明 |
| --- | --- |
| [产品范围](./product-scope.md) | 产品定位、支持边界与非目标 |
| [系统架构](./system-architecture.md) | 从 C# 或 Razor 到浏览器产物的完整职责划分 |

完成本目录后，应用开发者可进入[使用指南](../03-guides/README.md)开始配置与编写；维护者可进入[架构说明](../02-architecture/README.md)查阅稳定边界。先确认范围，再进入实现，能让后续决策始终落在同一份产品契约上。
