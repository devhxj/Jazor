# 产品概览

在进入项目、包与实现细节之前，先确认一个共同判断：Jazor 关心受支持的 C# 语义如何完整、有序地抵达浏览器；在浏览器中复现任意 .NET 运行时，则位于它的目标之外。范围一旦明确，后续的选型、配置与实现便有了统一的尺度。

| 文档 | 说明 |
| --- | --- |
| [产品范围](./product-scope.md) | 产品定位、支持范围与边界 |
| [系统架构](./system-architecture.md) | 从 C# 或 Razor 到浏览器产物的完整职责划分 |

读完本目录后，应用开发者可以进入[使用指南](../03-guides/README.md)开始配置与编写，维护者则可以进入[架构说明](../02-architecture/README.md)查阅稳定边界。先确认范围，再进入实现，每一次技术决策便始终锚定在同一份产品契约上。
