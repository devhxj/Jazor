## 文档分层
- `guides/`：维护者使用说明与治理规则
- `architecture/`：长期有效的架构、规范、专题入口
- `status/`：当前阶段判断、成熟度评审、当前推进重点
- `plans/`：当前仍在生效的行动方案
- `archive/`：历史材料与被合并后的原始文档
- `generated/`：生成产物文档说明
- `external/`：第三方依赖、缓存、工作副本文档说明
