# RazorVue 组件封装原则

> Status: active
> Scope: `ECMAScript.VueContract`、组件库 binding 与 RazorVue lowering。

## 目标

组件库的 C# API 必须优先使用标准 C# 和 Razor 语义，而不是在其上另建 Vue DSL。
Authoring 时首先使用 `[Parameter]`、`EventCallback`、`RenderFragment`、`record`、原生 `union`、集合初始化器和 C# 命名约定。元数据仅在 C# 不能忠实表达 Vue 合同时存在；异常 JavaScript 名称统一使用成员级 `[ECMAScriptName]`，`[Description("@#...")]` 作为通用兼容形式。

组件库的公开 authoring 类型沿用其组件前缀而不重复命名空间品牌：Element Plus 使用 `El*`，TDesign 使用 `T*`。仅 npm 根入口保留 `ElementPlus`、`TDesign` 完整品牌名；不保留旧长前缀别名，避免双重 API 表面。

## 最小合同

| 需求 | 默认 C# 表达 | 允许的例外元数据 |
| --- | --- | --- |
| 组件 prop | `[Parameter]` 属性，PascalCase 转 lower camel case | 在属性上用 `[ECMAScriptName("class")]` 等通用名称映射 |
| 普通事件 | `EventCallback` / `EventCallback<T>`，`OnClick` 转 `onClick` | 在属性上用 `[ECMAScriptName("onClick:close")]` 等 listener 名称 |
| 双向绑定 | `Value` + `ValueChanged`、`ModelValue` + `ModelValueChanged`或 `X` + `XChanged` | 仅在 Vue 属性名与 C# 属性名无法对应时显式覆盖 |
| 默认 slot | `ChildContent` / `DefaultContent : RenderFragment` | 无 |
| 普通 slot | `XContent : RenderFragment` 转 `x`；其余 PascalCase 参数名转 kebab-case | 在属性上用 `[ECMAScriptName("header.data-table-select")]` 等 slot 名称 |
| 对象值 | `record` | 无，结构化 record 在 JS 中擦除为对象 |
| 多分支值 | 原生 `union` | 分支类型可赋值重叠且必须保留精确 `AsX` 语义时使用 tagged fallback |
| 未建模 prop | `AdditionalAttributes` | 此是唯一公开 `object?` sink，不能借此弱化已知的强类型 API |
| npm 导入 | 无 C# 等价语法 | 类级导入标识，同时提供 specifier 与 export 名 |

## 当前审计

2026-08-05 初始审计：114 个组件、2478 个 `[Parameter]`、111 个手写 `IUnion`、2 个原生 `union`、245 个 `From(...)` 工厂。组件层上还有 57 条 `VueProp`、141 条 `VueLibraryEmit`、300 条 `VueSlot`，以及每个组件重复的 style/plugin 声明。

本轮收缩后，所有生产代码与测试夹具中的 `VueProp`、`VueSlot` 声明均已归零，对应 attribute 与 `VuePropKind` 已从共享 contract 删除。异常 prop、dot/camelCase slot 已迁移到成员级通用命名；ElementPlus 生成器仅为偏离约定的名称生成属性，并以标准 `[EditorRequired]` 表达 required 参数。ElementPlus 已不需要 emit 元数据，Vuetify 仅保留 16 条无法由 `OnX` 无损反推的异常原始事件名，TDesign 仅保留 `ValueChanged -> change` 一条非 model 映射。普通 `XChanged`、`OnX`、`ChildContent` / `DefaultContent`、`XContent` 与 PascalCase slot 均由 lowering 约定推断。

最终 union 清点：Vuetify 的 113 个值域和 TDesign 的 14 个值域全部使用原生 `union`；ElementPlus 的 46 个值域中 45 个使用原生 `union`，仅 `ElUploadBeforeUploadResult` 因 `File : Blob` 的可赋值重叠保留 tagged fallback。三个库的 `From(...)` 工厂均为 0。原生 union 的所有分支已证明两两不可赋值；`AsX` 投影、隐式标量/数组转换、集合初始化器，以及 `Null()`、`Auto()`、`Parent()`、`Cursor()` 等具有独立语义的入口继续保留。整体反射与编译契约同时守护原生存储形态、分支安全、fallback 精确分支和无 `From(...)` 公共表面。

| 现有特性 / 类型 | 生产 consumer | 结论 |
| --- | --- | --- |
| `VueLibraryComponent` | analyzer 组件识别、RazorVue named import lowering | 保留：C# 无法表达 npm specifier / named export |
| `ECMAScriptName` / `Description("@#...")` | compiler 与 RazorVue 成员名称映射 | 保留：这是绑定具体 Roslyn 符号的通用命名机制，适用于异常 prop、listener 与 slot 名称 |
| `VuePropAttribute` | 无 | 已删除：不能精确绑定 `new` 隐藏成员，prop 身份与名称分别由 `[Parameter]` 和成员级通用名称表达 |
| `VueLibraryEmit.Name` | RazorVue raw event / listener 映射 | 保留必要边界：`title-change` 等原始事件名不能总由 `onTitleChange` 无损反推 |
| `VueSlotAttribute` | 无 | 已删除：默认、普通及点号 slot 均可由参数类型、约定和成员级通用名称表达 |
| `VueLibraryStyle` / `VueLibraryPluginRequirement` | 无生产代码 consumer | 已删除：不以没有降级语义的重复 attribute 表示应用 bootstrap |
| `VuePropKind`、`AcceptsBinding`、`Required`、`DefaultExpression` | 无 | 已随 `VuePropAttribute` 删除。Razor SG 负责已知 parameter、required 与 bind 语法验证 |
| `VueEmitKind`、`PayloadTypeName` | 无生产代码 consumer | 已删除。`EventCallback<T>` 即是 payload 合同 |
| `VueSlot.Required`、`NamePattern`、`ContextTypeName`、`ContextParameterName` | 无 | 已随 `VueSlotAttribute` 删除：类型化 `RenderFragment<T>` 即是 slot context 合同 |
| `IVueLibraryComponent`、`VueLibraryComponentFlags` | 无生产 lowering/analyzer consumer | 已删除；类级 `VueLibraryComponent` import 标识是唯一权威 |

## 迁移顺序

1. 已完成：删除无 consumer 的 style/plugin 声明和相关断言。
2. 已完成：在 library component lowering 中增加无 attribute 的 `X` + `XChanged` model 约定，并以官方 Razor SG 用例回归。
3. 已完成：所有 RazorVue 组件按 `X` + `XChanged` 推断 model update，普通事件按 `OnX` 推断 kebab-case 原始事件名；仅保留异常 Vue 名称。
4. 已完成：删除默认、`XContent` 与 PascalCase/kebab-case slot 声明；`NamePattern` 因无产物 consumer 一并移除。
5. 已完成：RazorVue 以有效 `[Parameter]` 符号及成员级通用名称为唯一 prop/slot 合同；Vuetify、TDesign、ElementPlus、VueRoute、JazorAdmin 和测试夹具均已迁移，`VueProp` / `VueSlot` 兼容表面已删除。
6. 已完成：113 个 Vuetify 值域与 14 个 TDesign 值域全部迁移到原生 `union`；审计未发现需要 tagged fallback 的分支重叠，并已删除全部 `From(...)` 工厂和手写 tag/state wrapper。
7. 已完成：ElementPlus 的 46 个值域收缩为 45 个原生 `union` 和 1 个必要 tagged fallback；`File : Blob` 的分支重叠通过显式 tag 保持 `AsFile` / `AsBlob` 精确投影。`bool`、`File`、`Blob` 保留隐式赋值入口；因 C# 禁止接口来源的用户定义转换，`IPromise<T>` 使用公开 `new(...)` 构造入口。

## 不变约束

- 生产输入仍是官方 Razor SG 生成 C#；不回退到自定义 Razor 解析或 wrapper-JS 协议。
- 名称推断必须由 Roslyn 已绑定的 `[Parameter]` 属性和 `EventCallback` 类型决定，不依赖字符串猜测。
- 派生组件若要改变继承参数的 Vue 名称，必须显式声明 `new [Parameter]` 并把通用名称元数据标在新属性上；未隐藏的继承参数继续使用基类符号及其名称。
- 异常 Vue 名称和点号 slot 必须绑定到具体成员符号并有可测试的通用元数据路径；动态 slot 必须同时具备强类型 C# API 与产物 lowering，不能只保留声明。
- 不为兼容旧 DSL 增加新的 compiler feature；已退役的公开表面在迁移后视为完全移除。
